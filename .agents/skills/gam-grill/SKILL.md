Use this skill as the GAM-specific coordinator for the grilling portion of Agent P planning.

Run a `$grilling` session using `$gam-domain-modeling`.

After shared understanding is reached, use `$gam-requirements` to capture resolved answers in Requirement Specifications and unresolved answers as open questions.

Do not implement code or write tests.
